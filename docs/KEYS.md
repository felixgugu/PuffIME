# 按鍵與操作

## 方案切換

| 按鍵 | 行為 |
|---|---|
| `Ctrl+`` ` `` ` | 叫出方案選單 |
| `F4` | 叫出方案選單 |
| `CapsLock` | 切換 ASCII / 中文（長英文用） |

Shift 被保留給候選選字，**不用來切中英**。

## 嘸蝦米段

| 按鍵 | 行為 |
|---|---|
| `a`–`z` | 嘸蝦米字碼 |
| `,` `.` `[` `]` `'` | 也是嘸蝦米字碼 |
| 空白 | 有中文候選（含補全候選）時上屏；只剩英文原文時把空白加進緩衝（可連打英文）；其他無效碼不送出 |
| `1`–`9` `0` | 選第 n 個候選；只剩英文原文時改成輸入數字（見「連續英文」） |
| `Shift+1`–`Shift+0` | 選第 n 個候選（與上列相同） |
| `Enter` | 把目前輸入原樣上屏（英文） |
| `Tab` / 方向鍵 | 換候選 |
| `PageUp` / `PageDown` | 翻頁 |
| `Backspace` | 退回上一碼 |
| `Escape` | 取消 |
| `v` | 有候選且「碼+v」不是任何碼的前綴 → 上屏第 2 個候選；否則 `v` 當一般字碼 |
| `'` + 字碼 | 同音字查詢；第一個是原字，後面是同音字（依字頻） |
| `Shift+Space` | 循環符號形狀：半形 → 自然符號 → 全形 |

注意：`, .` 不再用於翻頁；請用 PageUp/PageDown。

### 前綴候選（逐碼縮小、常用字優先）

打一碼就列出所有以該碼開頭的字；每多打一碼，候選就減少。

| 輸入 | 候選（前幾個） |
|---|---|
| `i` | 後、我、說、這、讓、話、請、誰、該… |
| `a` | 對、也、會、點、過、或、發、錢…（876 個） |
| `aa` | 寸、丶、錢、鋪、鑫、鈴、鑰…（40 個） |
| `aaa` | 鑫、龘、鑆（3 個） |
| `ak` | 駐、鐵、錢、主、龍、鑽… |

- 精確碼候選一定先出，且維持字碼表順序；補全候選再依 `essay.txt` 字頻由高到低排序。
- 候選旁顯示的是「以目前輸入碼開頭」的最短碼；例如 `a` 下的「或」顯示 `aqoe`，不是全域最短碼 `he`。
- 候選太多時用 PageUp/PageDown 翻頁，或繼續打下一碼縮小。
- 嘸蝦米段每個碼都有前綴候選；注音段的殘碼（例如 `1`）也有字頻前綴候選，
  完整音節仍以精確碼為先。

### `v` 快速選第 2 個候選

- 條件：目前有候選（至少 2 個），且 `目前碼 + v` **不是**任何嘸蝦米碼的前綴。
- 符合 → 直接上屏第 2 個可見候選。
- 不符合（`碼+v` 是有效碼或前綴）→ `v` 正常輸入，讓你可以繼續打長碼。

例：

| 輸入 | 結果 |
|---|---|
| `ak` + `v` | 鐵（`ak` = 駐、鐵；`akv` 不存在） |
| `a` + `v` | `av` 是碼（族）→ 輸入 `av`，不選字 |
| `v` | 要（沒有候選，正常輸入） |
| `the` + `v` | 若 `thev` 不是前綴 → 第 2 個候選（英文 `the`） |

### 同音字查詢（`'`）

先按 `'`，再打同音字的正常拆碼：

| 輸入 | 候選 |
|---|---|
| `'neo` | 同（原字）、銅、童、桐、彤… |
| `'qnmr` | 規（原字）、歸、龜、硅… |
| `'doo` | 加（原字）、家、佳、夾、嘉… |
| `'uoo` | 台（原字）、臺、抬、苔… |

- 第一個候選是原字（也就是不加 `'` 時的第一個候選）；按空白會上屏它。
- 其餘同音字依 `essay.txt` 字頻排序，聲調必須相同。
- 破音字只取最常用讀音（例如 `台` 取 `ㄊㄞˊ`，不列 `ㄧˊ`）。
- 候選旁會顯示該字的最短拆碼；原字的拆碼與輸入相同時不重複顯示。
- `'` 單獨按仍是「、」；`''` 仍是「“」。
- `'` 只在第一碼有效，打在字碼中間不會觸發。

### 英文候選與連續英文

純小寫字母（可含 `'`、空白）會在候選列最後多一個「原文（英）」：

- `the` → `棫`、`the(英)`
- `he` → `或`、`恆`、`恒`、`he(英)`
- `was` → `was(英)`（沒有中文候選）
- `hello` → `hello(英)`（同上）

英文候選永遠在最後；要選它可以用它的號碼，或直接按 Enter（Enter 一定是原文）。

只剩英文原文時，空白和數字都會**加進緩衝**，preedit 會顯示
`hello world 42`；可以一直打完整句，最後按 Enter 一次上屏（含所有空白與數字）。
例如：

- `hello world` + Enter → `hello world`
- `hello123` + Enter → `hello123`
- `test 42` + Enter → `test 42`
- `was` + 空白 → 緩衝變 `was `，游標還在；打 `the` 再 Enter → `was the`
- `was` + `1` → 緩衝變 `was1`（不會選字上屏）
- `zzzz` + 空白 → 緩衝變 `zzzz `，Enter 才上屏 `zzzz `

打了數字後候選窗會收起（數字在 Rime 裡是獨立的 raw 片段），preedit 仍完整
顯示；按 Enter 就會上屏整串。

若輸入有中文候選（例如 `the` → 棫），空白和數字仍然是上屏／選字；要打該
英文單字請按 Enter。若輸入剛好是某個碼的前綴（例如 `out` 是 `outr` 的前綴），
也會出現中文補全候選，空白會上屏目前候選、數字會選字。

含 `, . [ ]` 等字元的無效拆碼仍維持「空白不送出」。

## 符號形狀

`Shift+Space` 循環三態：

| 狀態 | 中文標點 | ASCII 符號 | 例 |
|---|---|---|---|
| 半形（預設） | 半形 | 半形 | `,` → `,`、`c.` → `!`、`,dol` → `$` |
| 自然符號 | 全形 | 半形 | `,` → `，`、`c.` → `！`、`,dol` → `$` |
| 全形 | 全形 | 全形 | `,` → `，`、`c.` → `！`、`,dol` → `＄` |

- 自然符號保留 `，。、；：！？「」『』【】（）《》` 全形；
  `$ @ # % & = + - * / \ | < >` 這類 ASCII 符號半形。
- 半形把中文標點轉 ASCII：`，`→`,`；`[` / `]` 例外保留 `「` / `」`。
- 全形維持原表。
- `/X` 符號選單在三態下都可用。
- 切換無聲；下一個符號會顯示目前狀態。

## 注音段

第一碼 `` ` `` 進入注音，之後的按鍵是**大千鍵盤**：

```
1 ㄅ  q ㄆ  a ㄇ  z ㄈ
2 ㄉ  w ㄊ  s ㄋ  x ㄌ
e ㄍ  d ㄎ  c ㄏ
r ㄐ  f ㄑ  v ㄒ
5 ㄓ  t ㄔ  g ㄕ  b ㄖ
y ㄗ  h ㄘ  n ㄙ
u ㄧ  j ㄨ  m ㄩ
8 ㄚ  i ㄛ  k ㄜ  , ㄝ
9 ㄞ  o ㄟ  l ㄠ  . ㄡ
0 ㄢ  p ㄣ  ; ㄤ  / ㄥ  - ㄦ
6 ˊ  3 ˇ  4 ˋ  7 ˙  （一聲＝空白）
```

連按兩次 backtick 會直接上屏兩個 backtick，不進入注音；單一個 backtick
按 Enter 上屏。

**只有 Enter 上屏**：注音段的空白是聲調鍵，不是送出鍵；空白永遠不會上屏，
要上屏請按 `Enter`（或點候選）。

**無聲調先列全部**：只打音節（例如 `su`）時，會列出**所有聲調**的候選，
依字頻排序（你、呢、擬、尼…）；按 `Enter` 會上屏目前 highlight 的候選。
再按聲調鍵（`3` ˇ、`4` ˋ、`6` ˊ、`7` ˙）就只留該聲調（`su3` → 你、擬、妳…）。

**一聲用空白**：完整音節還沒帶聲調時按空白，會在 preedit 加上 `ˉ`，候選只留
一聲（`ru` → ㄐㄧ 全部聲調；`ru` + 空白 → ㄐㄧˉ 一聲）。之後用平數字、
`Shift+數字` 或 `Tab` 選字，再按 `Enter` 上屏。已帶聲調（`3`/`4`/`6`/`7`/`ˉ`）
的音節再按空白不會有動作。

**未完成的音節有前綴候選**：只按 `1`（ㄅ）、`q`（ㄆ）等單獨聲母時，
preedit 會是 `ㄅ`、`ㄆ`，不是原始按鍵；候選列會列出該聲母開頭的常用字
（`1` → 不、吧、把…），依字頻排序。按 `Enter` 上屏第一個；空白在這裡
不上屏也不加聲調。繼續按韻母或聲調就會縮小（`1u6` → ㄅㄧˊ → 鼻）。
已有精確碼的輸入（`5`、`1u`、`18`…）仍是精確候選在前，後面才接補全候選
（`5` → 之、只、至…，再 中、這…）。
多音節打到一半且沒有延伸碼時，例如 `su3c` 顯示 `ㄋㄧˇㄏ`，候選列只有
注音佔位，空白／Enter 不會送出。

| 按鍵 | 行為 |
|---|---|
| 空白 | **一聲**（完整音節、尚未帶聲調時）；已帶聲調或只有殘碼／補全候選時不動作。**空白永遠不上屏。** |
| `1`–`0` | **有聲調的音節後**（碼尾是 3/4/6/7 或一聲 `=`）選取第 n 個候選（不送出） |
| `1`–`0` | 尚未有聲調時是注音輸入（1=ㄅ、2=ㄉ、5=ㄓ、8=ㄚ、9=ㄞ、0=ㄢ） |
| `Shift+1`–`Shift+0` | 任何頁都可選取第 n 個候選（不送出） |
| `Tab` / `Shift+Tab` | 下一個／上一個候選（也是 highlight，不送出） |
| `PageUp` / `PageDown` | 翻頁 |
| `Escape` | 取消 |
| `Enter` | **上屏**目前 highlight 的候選；沒有候選或只有殘碼的佔位候選時不送出（不會上屏 `` `w8 `` 原文） |
| 連按兩次 `` ` `` | 直接上屏兩個 backtick（不進入注音） |

注音段的選字（數字、Shift+數字、Tab）都只會 **highlight**，按 `Enter` 才送出。
嘸蝦米段的數字選字則是選了就上屏；嘸蝦米與英文段的空白行為不受影響。

候選順序固定：嘸蝦米精確碼依字碼表、前綴補全依 `essay.txt` 字頻、注音依
`essay.txt` 字頻。`translator/enable_user_dict` 與 `zhuyin/enable_user_dict`
都設為 `false`，所以選字不會把某個候選提前。
無聲調與有聲調的單字碼放在同一份 `puffzhuyin` 字典，因此 `su` 的所有聲調
候選會依同一個字頻順序排列，不會出現「先一排一聲、再一排其他聲調」。
一聲另有帶 `=` 標記的別名（例如 `稽` 同時有 `ru` 和 `ru=`）；`ru=` 只列
ㄐㄧ 一聲的字。

## 符號選單

第一碼 `/` 進入 Weasel 內建的符號分類（`symbols.yaml`）。輸入分類碼後，
候選列就是該分類；用數字/空白選字。

| 輸入 | 內容 |
|---|---|
| `/jt` | 箭頭 ↑↓←→… |
| `/sx` | 數學 ±÷×∈… |
| `/bq` | 表情 ☻☺☹ |
| `/fh` | 符號、電腦 |
| `/0`–`/10` | 數字、分數 |
| `/xh` | 星號 |
| `/fk` | 方塊 |
| `/bg` | 八卦 |
| `/lm` | 羅馬數字 |

注意：`/` 不是嘸蝦米字碼，所以不會和嘸蝦米衝突；`, . [ ] '` 仍是嘸蝦米字碼。

## 簡碼提示與忘記清單

| 按鍵 | 行為 |
|---|---|
| 嘸蝦米長碼 | 候選字旁顯示最短碼（例如 `a`），不帶 `簡:` 標籤 |
| 注音候選 | **不顯示** `簡/拆`，避免候選窗被最長的註記撐寬 |
| `,,fk` | 開啟忘記清單，依最後使用時間新→舊；選了上屏該字 |
| `,,fl` | 只顯示最新一次從注音上屏的字（詞會列出該次所有字）與 `簡/拆`；按 `Esc` 關閉 |

例：

| 輸入 | 結果 |
|---|---|
| `feba` + 空白 | 對（候選旁 `a`） |
| `` ` `` + `su3` | 你（注音候選旁沒有 `簡/拆`） |
| `` ` `` + `su3` + `Enter` | 你；這次注音上屏會被記錄 |
| `,,fk` | 你、我、…（`簡/拆` + 次數） |
| `,,fl` | 上一次上屏的字（例如 天，`簡: edn`） |

資料檔：`%APPDATA%\Rime\puffime_forgotten.tsv`

**注意**：`,,fk` 的 preedit 會顯示 `k`（前綴 `,,f` + 代碼 `k`），`,,fl` 顯示 `l`；候選列才是清單。
注音候選不顯示字碼是刻意的：Weasel 會用最長的 comment 決定整排候選窗寬度，
把 `簡/拆` 放在候選旁會讓注音候選窗變得很大。

註記字級與顏色可在 `weasel.custom.yaml` 調整：

```yaml
style:
  font_point: 14
  comment_font_point: 10
  comment_font_face: "Microsoft JhengHei"
preset_color_schemes:
  puff:
    comment_text_color: 0x888888
    hilited_comment_text_color: 0x666666
```

例：

| 輸入 | 結果 |
|---|---|
| `` ` `` + `su3` + `Enter` | 你（只留三聲） |
| `` ` `` + `su3` + 空白 | 不上屏（空白是聲調鍵） |
| `` ` `` + `su` + `Enter` | 你（所有聲調，常用字在前） |
| `` ` `` + `su` + 空白 | 縮小到 ㄋㄧ 一聲（妮…），再按 `Enter` 上屏 |
| `` ` `` + `ji3` + `Enter` | 我 |
| `` ` `` + `ji3` + `2` | 選取第二個候選（highlight，不送出） |
| `` ` `` + `ji3` + `2` + `Enter` | 婑 |
| `` ` `` + `ji3` + `2` + `3` + `Enter` | 捰（改成第三個再送出） |
| `` ` `` + `su` + `Shift+2` + `Enter` | 呢（`su` 所有聲調，第 2 個是呢） |
| `` ` `` + `u` + 空白 + `Enter` | 一（空白＝一聲） |
| `` ` `` + `wu0` + `Enter` | 天 |
| `` ` `` + `su3cl3` + `Enter` | 你好 |
| `` ` `` + `5j/eji6` + `Enter` | 中國 |
| `` ` `` + `5j/` + 空白 + `eji6` + `Enter` | 中國（一聲用空白） |
| `` ` `` + `ru` + 空白 + `Enter` | 機（ㄐㄧ 一聲第一個） |
| `` ` `` + `ru` + 空白 + PageDown ×2 + `Enter` | 稽（ㄐㄧ 一聲第 19 個） |
| `` ` `` + `ru` + 空白 + `t86` + `Enter` | 稽查 |
| `` ` `` + `ji2` + `Enter` | 不送出 `ji2`（留在緩衝，可 Backspace） |

注音段的 preedit 會顯示注音符號（`ㄋㄧˇ`、`ㄐㄧˉ`），不是原始按鍵。

**要在有聲調的音節後面接一個數字開頭的新音節**（例如 ㄉ、ㄅ、ㄓ），先按 `Enter`
上屏目前候選，再打那個數字。

## Android / Trime 注音鍵盤

Android 版多了兩顆螢幕鍵（不影響 Windows）：

| 按鍵 | 行為 |
|---|---|
| 底部 **「中文」/「注音」** | 切中文、換成 ㄅㄆㄇ 注音鍵盤、進入注音 |
| 長按 **「注音」** | 切換中文／英文 |
| 注音上屏（Enter／點候選） | 自動切回 QWERTY 嘸蝦米鍵盤 |
| 注音鍵盤左下 **「嘸蝦米」** | 取消注音、回到 QWERTY 嘸蝦米鍵盤（不上屏） |

注音鍵盤的按鍵就是上面的大千鍵位，但直接標示 `ㄅ ㄆ ㄇ …`，不用背對照。
例如按 `ㄋ` `ㄧ` `ˇ`、`Enter` → 你；按 `ㄅ` `ㄚ`、`Enter` → 吧；
按 `ㄐ` `ㄧ`、空白（一聲）、`Enter` → 機，翻頁可選 `稽`。

注音鍵盤沿用 Trime 預設主題內建的 Bopomofo 布局；使用第三方主題時按鍵可能不同。

## 邊界行為

- `` ` `` 只在**第一碼**有效。已經打了 `a` 再按 `` ` `` 會被忽略，不會把 `a` 上屏，也不會進注音。
- 在注音段若按到非注音鍵（例如 `[`），該鍵不會進入注音緩衝。
- `CapsLock` 進 ASCII 模式後，所有按鍵直接輸出英文；再按一次 CapsLock 回中文。
